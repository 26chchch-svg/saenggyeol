# 🌙 생결 계산기

마지막으로 쓴 날만 넣으면, 생리결석을 언제 다시 쓸 수 있는지 알려 주는 계산기예요.

👉 **사이트 바로가기:** (배포 후 주소를 여기에 적어 주세요)

## 만든 이유

학교 커뮤니티에 "지금 생결 쓸 수 있나요?"라는 질문이 반복해서 올라왔어요.
규칙은 단순하지만 날짜를 직접 세다 보면 헷갈리기 쉬워서, 누구나 바로 확인할 수 있는 도구를 만들었어요.

## 계산 규칙

- 쓴 날로부터 20일 뒤부터 다시 쓸 수 있어요. (예: 10월 9일 사용 → 10월 29일부터 가능)
- 주말과 공휴일도 날짜에 포함해요.
- 기말고사 기간(시작일, 종료일 포함)에는 주기와 상관없이 쓸 수 없어요.

## 기능

- 고른 날에 쓸 수 있는지, 안 된다면 이유와 가장 빠른 날을 알려 줘요.
- 달력에서 대기 기간, 기말고사 기간, 다시 쓸 수 있는 첫날을 한눈에 볼 수 있어요.
- 입력한 날짜는 저장하거나 전송하지 않아요. 모든 계산은 브라우저 안에서만 이루어져요.

## 학기마다 업데이트하는 법

`exams.js` 파일의 기말고사 날짜만 바꾸면 돼요.

```js
window.EXAM_PERIODS = [
  { name: "2027-1학기 기말고사", start: "2027-06-14", end: "2027-06-19" },
];
```

## 기술

HTML, CSS, JavaScript (라이브러리 없음) · GitHub Pages로 배포

## 안내

학교 공식 서비스가 아니에요. 정확한 규정은 학사 공지를 확인해 주세요.
